# Major Assignment - Sorting Algorithms

This folder contains the code and graph for comparing **Bubble Sort**, **Selection Sort**, **Insertion Sort**, and **Merge Sort** on array sizes **5, 10, 50, and 100** (averaged over 10 runs in microseconds).

## Files
- `sorting_analysis.cpp` — C++ code that runs the sorting algorithms and measures execution time.
- `plot_results.py` — Python code that draws the chart (`sorting_graph.png`).
- `sorting_graph.png` — The generated graph image.

## How to Run
1. Run `sorting_analysis.cpp` in a C++ compiler to get the average times.
2. Run `plot_results.py` in Python (with `matplotlib`) to generate `sorting_graph.png`.
